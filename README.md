# TicTacToe Roguelike em Unity

Este repositório guarda o protótipo original do jogo da velha com combate por turnos e runas. O projeto seguiu em Godot, com reaproveitamento da lógica de jogo em C#.

Veja a [versão em Godot](https://github.com/Facnelli/tic-tac-toe-godot) para conhecer o estado atual do projeto, executar o jogo e consultar a documentação da migração.
